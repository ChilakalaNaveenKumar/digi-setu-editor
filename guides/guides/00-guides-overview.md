# Guides – Practical How-To Material

The guides cover *task-oriented* recipes that don't fit the
single-function reference pages. Each one assumes you already know
the basics from the tutorial and reference.

| Guide                                          | When to read it                                             |
| ---------------------------------------------- | ----------------------------------------------------------- |
| [01 – For LaTeX users](./01-for-latex-users.md) | You're switching from LaTeX and want a translation table. |
| [02 – Page setup](./02-page-setup.md)           | Sizes, margins, headers/footers, page numbers, columns.   |
| [03 – Tables](./03-tables.md)                   | All the ways to build tables (from quick `table[..]` to fully accessible PDF/UA). |
| [04 – Accessibility](./04-accessibility.md)     | Producing tagged PDF / PDF/UA / PDF/A / accessible HTML.   |
