# `math.lr` — delimiter matching and scaling

Typst auto-scales **matched** delimiter pairs (`( )`, `[ ]`, `{ }`, `⟨ ⟩`, `| |`, ...) to fit the height of their content. `lr()` and friends give you finer control: scale unmatched delimiters, force a specific size, or disable auto-scaling entirely.

## `math.lr(body, size: 100% + 0pt)` — explicit delimiter pair

| Param  | Type      | Default        | Notes                                                         |
| ------ | --------- | -------------- | ------------------------------------------------------------- |
| `body` | content   | required       | Content **including** the delimiters at both ends.            |
| `size` | relative   | `100% + 0pt`    | Size relative to wrapped-content height.                      |

```typst
$ lr(]sum_(x=1)^n], size: #50%) x $
```

## Helpers built on `lr`

All accept `size:` and a single `body` argument.

| Helper        | Renders          | Default delimiter |
| ------------- | ---------------- | ----------------- |
| `abs(x)`       | `|x|`            | `|`               |
| `norm(x)`      | `‖x‖`            | `‖`               |
| `floor(x)`     | `⌊x⌋`            | `⌊ ⌋`             |
| `ceil(x)`      | `⌈x⌉`            | `⌈ ⌉`             |
| `round(x)`     | `⌊x⌉`            | `⌊ ⌉`             |

## `math.mid(body)` — vertically scale to surrounding lr group

Scales `body` to match the height of the **nearest** enclosing `lr(...)` group (typically used in set-builder notation).

```typst
$ { x mid(|) sum_(i=1)^n w_i abs(f_i (x)) < 1 } $
```

## Disabling auto-scaling

| Goal                                 | How                                |
| ------------------------------------ | ---------------------------------- |
| One specific delimiter (don't match) | Escape with backslash: `\{`, `\(`, `\|` |
| Globally for the whole document      | `#set math.lr(size: 1em)`           |

## Pitfalls

- `lr()` requires the **delimiters to be inside `body`** — it doesn't add them for you. `lr(](sum_(x=1)^n], ...)` is correct; `lr(sum_(x=1)^n)` doesn't add anything.
- `mid()` only scales when *inside* an `lr(...)` group. Outside it, the delimiter renders at its normal size.
- Auto-scaling matches based on syntactic pairs, not the rendered output — if your symbols come from a code variable, Typst can't see the pair structure; use `lr()` explicitly.
