# `math.op(text, limits: false)` — text operator

Renders a piece of text in **upright** style with operator-like spacing — the way `sin`, `log`, `lim` are typeset. Most of the time you don't need to call `op()` yourself: Typst predefines the common ones.

## Parameters

| Param    | Type     | Default  | Notes                                                            |
| -------- | -------- | -------- | ---------------------------------------------------------------- |
| `text`   | content   | required | The operator text.                                                |
| `limits` | bool      | `false`   | If `true`, attachments display as **limits** (above/below) in block mode. |

## Predefined operators (no `op()` needed)

`arccos`, `arcsin`, `arctan`, `arg`, `cos`, `cosh`, `cot`, `coth`, `csc`, `csch`, `ctg`, `deg`, `det`, `dim`, `exp`, `gcd`, `lcm`, `hom`, `id`, `im`, `inf`, `ker`, `lg`, `lim`, `liminf`, `limsup`, `ln`, `log`, `max`, `min`, `mod`, `Pr`, `sec`, `sech`, `sin`, `sinc`, `sinh`, `sup`, `tan`, `tanh`, `tg`, `tr`.

These behave like `op("sin")`, etc.

## Defining your own

```typst
#let argmin = math.op("argmin", limits: true)

$ argmin_(x in RR) f(x) $
```

`limits: true` is appropriate for operators that take an argument *under* them (`argmin`, `argmax`, `inf`, `sup`).

## Globally moving inline operator scripts to limits

```typst
#show math.equation.where(block: false): set math.op(limits: true)
```
