# `h(amount, weak: false)` — horizontal spacing

Inserts horizontal spacing into a paragraph. Accepts absolute, relative, or fractional amounts.

## Parameters

| Param    | Type                  | Default  | Notes                                         |
| -------- | --------------------- | -------- | --------------------------------------------- |
| `amount` | relative / fraction    | required | How much spacing.                              |
| `weak`   | bool                   | `false`   | If `true`, collapses at line edges; among adjacent weak spaces only the largest wins. |

## Amount kinds

| Form        | Example       | Effect                                            |
| ----------- | ------------- | ------------------------------------------------- |
| Absolute    | `h(1cm)`       | Fixed gap.                                         |
| Relative    | `h(30%)`       | Percentage of container width.                    |
| Fractional  | `h(1fr)`       | Distributes remaining line space (see below).     |

## Fractional `h` — alignment without paragraph breaks

`align()` is block-level — it forces a new paragraph. To align pieces **on the same line**, use fractional `h`:

```typst
Left #h(1fr) Right                    // pushes "Right" to the right edge
Left #h(1fr) Center #h(1fr) Right     // even thirds
Left #h(2fr) Mid #h(1fr) Right        // Mid sits 2/3 across
```

## Math-mode spacing constants

Inside `$...$`, these constants give predictable spacing:

| Const     | Width      |
| --------- | ---------- |
| `thin`    | 1/6 em     |
| `med`     | 2/9 em     |
| `thick`   | 5/18 em    |
| `quad`    | 1 em       |
| `wide`    | 2 em       |

```typst
$ a quad b $
$ "Let " thin x in NN $
```

## Weak spacing

`weak: true` makes the spacing **collapse**:

- At the **start** or **end** of a paragraph it disappears.
- Among **adjacent weak spaces**, only the largest survives.
- Adjacent **markup spaces** are also swallowed (force a real space with `~` or `#" "` if needed).

Useful when a custom show rule may or may not have spacing context around it.
