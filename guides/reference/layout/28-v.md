# `v(amount, weak: false)` — vertical spacing

Inserts vertical spacing into a flow of blocks. The vertical counterpart to [`h`](./11-h.md).

## Parameters

| Param    | Type                  | Default  | Notes                                              |
| -------- | --------------------- | -------- | -------------------------------------------------- |
| `amount` | relative / fraction    | required  | Spacing amount.                                    |
| `weak`   | bool                   | `false`   | Collapsing behavior at flow edges.                  |

## Amount kinds

| Form        | Example       | Effect                                            |
| ----------- | ------------- | ------------------------------------------------- |
| Absolute    | `v(12pt)`      | Fixed gap.                                         |
| Relative    | `v(40%)`       | Percentage (rarely useful for vertical).          |
| Fractional  | `v(1fr)`       | Distributes remaining vertical space (e.g., to push content to bottom of page). |

## Weak spacing

`weak: true` is more aggressive than for `h`:

- Collapses at the **top/bottom** of a flow.
- Among adjacent weak spaces, only the largest survives.
- **Always overrides** adjacent paragraph spacing, even if the paragraph spacing is larger.

Useful around math blocks, code blocks, or custom show rules where you want a controlled amount of breathing room without doubling up on existing paragraph spacing.

## Common patterns

| Goal                                  | Recipe                       |
| ------------------------------------- | ---------------------------- |
| Push content to the bottom of a page  | `Header` ⏎ `#v(1fr)` ⏎ `Footer` |
| Tight gap above & below a block       | `#v(4pt, weak: true)` … `#v(4pt, weak: true)` |
| Force a fixed gap regardless of paragraphs | `#v(20pt)` (non-weak)    |
