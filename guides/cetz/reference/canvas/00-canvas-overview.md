# Canvas — Overview

The `canvas` module exposes a single function — `canvas(...)` — which is the
entry-point for every CeTZ drawing.

| Function | Page |
| -------- | ---- |
| `canvas(...)` | [`01-canvas.md`](./01-canvas.md) |

`canvas` returns `content`. By default it is **block-level**; setting
`baseline:` makes it behave like a `box` for inline use.

See also the higher-level walk-through: [`../../tutorial/02-the-canvas.md`](../../tutorial/02-the-canvas.md).
