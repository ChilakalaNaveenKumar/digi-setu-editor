# `path-util.last-subpath-end()` — End Of Last Subpath

Returns the end point of the last subpath in `path` — the natural "next"
position for path-construction code.

## Signature

```text
last-subpath-end(path: array) -> vector
```

## Parameters

- **`path`** — array of subpaths.
