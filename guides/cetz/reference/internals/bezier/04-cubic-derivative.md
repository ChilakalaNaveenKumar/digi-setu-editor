# `bezier.cubic-derivative()` — Cubic Bézier Derivative

Returns the derivative (tangent vector) of a cubic Bézier curve at `t`.

## Signature

```text
cubic-derivative(a: vector, b: vector, c1: vector, c2: vector, t: float) -> vector
```

## Parameters

Same as [`cubic-point`](./03-cubic-point.md).
