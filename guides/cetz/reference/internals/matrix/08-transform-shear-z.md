# `matrix.transform-shear-z()` — Shear Along Z

Returns a 4×4 affine matrix that shears along the Z axis with the given
factor — used by oblique projection.

## Signature

```text
transform-shear-z(factor: float) -> matrix
```

## Parameters

- **`factor`** — shear factor.
