# `matrix.transform-rotate-z()` — Rotation About Z

Returns a 4×4 affine matrix that rotates about the Z axis. This is the
"normal" 2D rotation.

## Signature

```text
transform-rotate-z(angle: angle) -> matrix
```

## Parameters

- **`angle`** — Typst angle.
