# `matrix.transform-rotate-y()` — Rotation About Y

Returns a 4×4 affine matrix that rotates about the Y axis.

## Signature

```text
transform-rotate-y(angle: angle) -> matrix
```

## Parameters

- **`angle`** — Typst angle.
