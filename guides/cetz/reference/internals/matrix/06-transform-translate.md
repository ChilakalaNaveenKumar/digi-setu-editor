# `matrix.transform-translate()` — Translation Matrix

Returns a 4×4 affine matrix that translates by `(x, y, z)`.

## Signature

```text
transform-translate(x: float, y: float, z: float) -> matrix
```

## Parameters

- **`x`**, **`y`**, **`z`** — translation along each axis.
