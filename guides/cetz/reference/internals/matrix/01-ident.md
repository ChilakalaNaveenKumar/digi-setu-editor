# `matrix.ident()` — Identity Matrix

Returns a square identity matrix of the requested size (CeTZ uses size `4`
for affine transforms).

## Signature

```text
ident(size: int = 4) -> matrix
```

## Parameters

- **`size`** — number of rows/columns; defaults to `4`.
