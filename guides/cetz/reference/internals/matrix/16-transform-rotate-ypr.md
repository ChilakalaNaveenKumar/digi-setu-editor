# `matrix.transform-rotate-ypr()` — Yaw / Pitch / Roll

Returns a 4×4 affine rotation built from yaw/pitch/roll angles —
also called Tait–Bryan angles.

## Signature

```text
transform-rotate-ypr(yaw: angle, pitch: angle, roll: angle) -> matrix
```

## Parameters

- **`yaw`**, **`pitch`**, **`roll`** — Typst angles in YPR convention.
