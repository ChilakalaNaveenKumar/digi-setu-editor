# `matrix.round()` — Round Entries

Rounds every entry of a matrix to the requested precision (number of
decimal digits).

## Signature

```text
round(mat: matrix, precision: int = 10) -> matrix
```

## Parameters

- **`mat`** — input matrix.
- **`precision`** — number of decimal digits to keep; defaults to `10`.
