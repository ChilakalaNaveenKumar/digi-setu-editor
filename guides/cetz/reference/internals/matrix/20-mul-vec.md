# `matrix.mul-vec()` — Generic Matrix·Vector Product

Multiplies a matrix by a vector — the general N-dimensional version.

## Signature

```text
mul-vec(mat: matrix, vec: vector) -> vector
```

## Parameters

- **`mat`** — input matrix (rows × cols).
- **`vec`** — vector with `cols` entries.
