# `matrix.column()` — Extract a Column

Extracts the `n`-th column of a matrix as a vector.

## Signature

```text
column(mat: matrix, n: int) -> vector
```

## Parameters

- **`mat`** — source matrix.
- **`n`** — zero-based column index.
