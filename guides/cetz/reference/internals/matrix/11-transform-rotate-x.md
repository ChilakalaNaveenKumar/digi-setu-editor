# `matrix.transform-rotate-x()` — Rotation About X

Returns a 4×4 affine matrix that rotates about the X axis by the given
angle.

## Signature

```text
transform-rotate-x(angle: angle) -> matrix
```

## Parameters

- **`angle`** — Typst angle (e.g. `45deg` or `0.7854rad`).
