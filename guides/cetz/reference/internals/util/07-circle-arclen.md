# `util.circle-arclen()` — Arc Length Of A Circle

Returns the arc length of a circular arc with the given radius and
swept angle.

## Signature

```text
circle-arclen(radius: float, angle: angle = 360deg) -> float
```

## Parameters

- **`radius`** — circle radius.
- **`angle`** — swept angle (defaults to a full circle).
