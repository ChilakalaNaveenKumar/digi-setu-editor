# `util` — Miscellaneous Utilities

`cetz.util` is the catch-all helper module — geometry primitives,
dictionary helpers, number/length resolution, padding & corner-radius
parsing, content measurement, and so on.

The module is exposed at `cetz.util.<fn>`.
