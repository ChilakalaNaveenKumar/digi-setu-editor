# `util.line-normal()` — Unit Normal Of A Line

Returns the unit normal vector of the line segment `(a, b)` — i.e. the
perpendicular direction in the XY plane.

## Signature

```text
line-normal(a: vector, b: vector) -> vector
```

## Parameters

- **`a`**, **`b`** — line endpoints.
