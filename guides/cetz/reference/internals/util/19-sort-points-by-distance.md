# `util.sort-points-by-distance()` — Sort Points By Distance

Sorts an array of points by their Euclidean distance from `base`,
nearest first.

## Signature

```text
sort-points-by-distance(base: vector, pts: array) -> array
```

## Parameters

- **`base`** — reference point.
- **`pts`** — list of points to sort.
