# `complex.im()` — Imaginary Part

Returns the imaginary part of a complex number.

## Signature

```text
im(V: complex) -> float
```

## Parameters

- **`V`** — a complex number `(re, im)`.

## Reference implementation

```typst
#let im(V) = V.at(1)
```
