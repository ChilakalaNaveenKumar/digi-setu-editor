# `vector.dist()` — Euclidean Distance

Returns the Euclidean distance between two vectors — equivalent to
`len(sub(a, b))`.

## Signature

```text
dist(a: vector, b: vector) -> float
```

## Parameters

- **`a`**, **`b`** — endpoints.
