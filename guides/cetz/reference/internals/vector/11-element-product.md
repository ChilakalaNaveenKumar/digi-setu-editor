# `vector.element-product()` — Hadamard Product

Returns the element-wise product of two vectors `(a₀·b₀, a₁·b₁, …)`.

## Signature

```text
element-product(a: vector, b: vector) -> vector
```

## Parameters

- **`a`**, **`b`** — operands.
