# `vector.add()` — Element-wise Addition

Returns the element-wise sum of two vectors.

## Signature

```text
add(v1: vector, v2: vector) -> vector
```

## Parameters

- **`v1`**, **`v2`** — operands; each is padded to the longer length with
  `0` (via `as-vec`).
