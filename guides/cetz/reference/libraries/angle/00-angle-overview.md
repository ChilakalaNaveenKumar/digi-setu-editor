# Angle Library — Overview

`cetz.angle` provides decorators for marking angles between two rays sharing
a common origin.

| Function | Purpose | Page |
| -------- | ------- | ---- |
| `cetz.angle.angle(origin, a, b, ...)` | Arc between two rays | [`01-angle.md`](./01-angle.md) |
| `cetz.angle.right-angle(origin, a, b, ...)` | The right-angle "square" decorator | [`02-right-angle.md`](./02-right-angle.md) |
