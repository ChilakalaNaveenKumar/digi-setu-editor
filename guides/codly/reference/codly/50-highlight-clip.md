# `highlight-clip`

Whether the highlight box clips code that overflows it. See Typst's
built-in `block.clip` for the underlying behaviour.

| Field | Value |
| ----- | ----- |
| Type | `bool` |
| Default | `true` |
| Contextual function | yes |
| Automatically reset | no |
| Released in 1.3.1 | yes |
