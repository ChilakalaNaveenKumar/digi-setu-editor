# `highlight-radius`

The radius of the [highlights](./44-highlights.md).

| Field | Value |
| ----- | ----- |
| Type | `length` |
| Default | `0.32em` |
| Contextual function | yes |
| Automatically reset | yes |
| Released in 1.3.1 | yes |

## Pitfalls

- Unlike most cosmetic settings this **resets after each block**.
