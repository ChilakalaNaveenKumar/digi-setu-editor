# `highlight-outset`

The outset of the highlight blocks. Can also be a dictionary with the
same keys as Typst's built-in `block.outset`.

| Field | Value |
| ----- | ----- |
| Type | `length` or `dictionary` |
| Default | `0em` |
| Contextual function | yes |
| Automatically reset | no |
| Released in 1.3.1 | yes |
