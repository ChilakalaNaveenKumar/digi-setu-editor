# `lang-radius`

The radius of the border of the language pill. Only used when
[`lang-format: auto`](./28-lang-format.md).

| Field | Value |
| ----- | ----- |
| Type | `length` |
| Default | `0.32em` |
| Contextual function | yes |
| Automatically reset | no |
| Released in 1.3.1 | yes |

## Example

```typst
#codly(lang-radius: 10pt)
```py
print('Hello, world!')
print('Goodbye, world!')
```
```

See [`examples/25-lang-radius/25-lang-radius.typ`](./examples/25-lang-radius/25-lang-radius.typ).
