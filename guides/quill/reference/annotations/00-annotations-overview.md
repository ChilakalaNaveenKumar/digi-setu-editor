# Annotations — overview

The reference for `annotate(...)` lives under
[`reference/decorations/08-annotate.md`](../decorations/08-annotate.md).
This folder collects deeper recipes that show the **expressive range**
of `annotate`:

| Page | Scenario |
| ---- | -------- |
| [`01-readout-brace.md`](01-readout-brace.md) | A vertical brace + label above two columns (the manual's "Readout circuit"). |
| [`02-cell-centres-polygon.md`](02-cell-centres-polygon.md) | Drawing a filled polygon between cell centres. |
| [`03-arrow-overlay.md`](03-arrow-overlay.md) | Hand-drawn arrows pointing at specific gates. |

If you only need a labelled rectangle, prefer [`gategroup`](../decorations/06-gategroup.md). For a phase boundary, use
[`slice`](../decorations/07-slice.md). `annotate` is for everything else.
